About Blue Bird

Blue Bird provides built-in routing, JWT authentication, validation, performance caching, SEO management, and raw HTML templates with no extra overhead.

Framework Capabilities

HTML Minifier

Every HTML view is parsed, comments are stripped, and whitespace is compressed instantly, delivering minimum payload sizes to ensure superior SEO metrics.

In-Memory Cache

The framework caches fully compiled HTML outputs in RAM memory with configurable time-to-live expiration (TTL), ensuring sub-millisecond response times in production.

Pure API Focus

Designed to serve as a fast API and static content backend. Perfect to run independently, or to easily migrate to newer decoupled frontend tools later on.

Gzip Compression

All textual assets, compiled pages, and REST API payloads are compressed via Gzip before network transit to ensure low latency and high score audits.
